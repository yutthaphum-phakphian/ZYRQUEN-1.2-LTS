# CodeVoice AI Milestone Index

This directory is the canonical home for milestone reports.

## Current capability groups

- `developer-repair/` — developer verification, repair planning, patching and workflow reports.
- `recovery-reliability/` — recovery, integrity, governance, chaos certification and reliability reports.
- `runtime-foundation/` — runtime execution, control-plane and real-tool execution reports.
- `legacy-v-series/` — historical V-series reports retained for traceability. These are historical labels only; new work uses capability/milestone names.

## Source of truth

The working source tree is the repository root (`nextwork`). ZIP releases are snapshots only and are not used as the development source.

## Release policy

Continue development in the source tree. Create a consolidated release package only after a larger capability set is complete and regression-tested.
