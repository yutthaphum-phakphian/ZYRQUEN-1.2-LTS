# V17 Self-Contained Real Agent Runtime Reality Report

## Executive Summary

This V17 pass makes CodeVoice AI internally usable without external providers. It
reuses the existing V12 runtime/tool boundary and adds a real local workspace
runtime, actual internal tool execution, persistence metadata, task objects,
checkpoint creation/integrity verification, snapshots, memory writes/search,
path-traversal protection, permission enforcement, observable events, and a
Self-Contained Runtime panel on desktop/mobile.

External OAuth, REST providers, databases, MCP, GraphQL, WebSocket, external
webhooks, and secure external credential vaults remain unavailable by design.
They are not simulated.

## Implemented

- `SelfContainedRuntime` backed by the current project context and local
  persistence when the browser persistence API is available.
- Real internal tools: read/create/update/rename/delete/list/search files,
  project summary/rules/knowledge, memory save/search, validation, diff
  metadata, preview metadata, and export readiness.
- Safe normalized paths with `PATH_TRAVERSAL_BLOCKED` for `../`, absolute paths,
  and invalid paths.
- Mutation tools have real `REVIEW`/`DANGEROUS` permission gates; missing
  approval returns `PERMISSION_DENIED` and does not mutate project state.
- Real task objects with persistent status/result/error fields.
- Local checkpoints with context and integrity hash.
- Snapshot create/restore with integrity verification.
- Runtime event feed generated from actual tool calls and failures.
- V17 Self-Contained Runtime panel exposing actual file/tool/event state.
- Existing V13–V16 external infrastructure panel remains intact and reports
  unavailable provider infrastructure honestly.

## Security tests

- Path traversal blocked.
- Mutating tools require explicit approval input at the runtime boundary.
- Delete/export are dangerous; create/update/rename are review-level.
- Runtime events contain summaries/evidence only; raw external credentials are
  not accepted or stored.
- Checkpoint tampering fails integrity verification.
- V16 SSRF, SQL, webhook HMAC, and export secret scans remain active.

## Known limitations

- The browser local persistence API is the available persistence mechanism in
  this app; it is not presented as server/database durability.
- Internal file tools operate on the CodeVoice project model in browser state,
  not arbitrary OS files outside the project workspace.
- The known Vite `__dirname` future config-loader warning and bundle-size
  advisory remain non-blocking technical debt.
- No V18 work was started.
